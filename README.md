# Edit Distance (Levenshtein) Visualizer

An interactive visualizer for the Levenshtein Edit Distance algorithm.

## 🔗 Live Demo
https://wagd-haroon.github.io/Edit-Distance-Levenshtein-visualizer/

## What is Edit Distance?
Edit Distance is the minimum number of operations (insert, delete, replace)
needed to convert one string into another.

## Features
- Visual step-by-step matrix
- Interactive input
